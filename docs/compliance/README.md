**Last updated:** 2026-08-30
**Status:** DRAFT — All documents pending regulatory review

support documentation for the Neuridion AI-assisted post-market surveillance
screening platform. Repository documents do not prove the configuration or
status of any deployment.

A public-facing AI transparency page is available at [`/ai-transparency`](/ai-transparency) covering system overview, models used, human oversight measures, data handling, and limitations.

## Review Process

All documents marked `DRAFT`, `DRAFT TEMPLATE`, or `[REVIEW: ...]` require
qualified quality/regulatory review and, where identified, legal review before
external reliance. These materials are not legal opinions, certificates, a
universal accuracy claim, or a completed validation of Neuridion in a customer's
QMS. Technical statements are point-in-time descriptions and must be checked
against the identified release and deployed configuration before issue.
